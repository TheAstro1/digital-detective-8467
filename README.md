# Digital Detective

A worked reference for the Diwali independent-learning assignment **The Digital Detective: Explore Your Computer • Build a Mini System Report**. The missions introduce computer fundamentals, command-line tools, operating systems, Python, data representation, Git/GitHub, and networking.

## Topics explored

- The input–process–output–storage (IPOS) cycle, hardware, software, and embedded computer systems
- Terminal navigation, safe file operations, flags, pipes, and package managers
- Operating-system responsibilities, running processes, paths, storage, and permissions
- Running Python and comparing compiled and interpreted execution
- Decimal, binary, and hexadecimal values; ASCII and UTF-8
- Git's working tree, staging area, commits, branches, and Pull Requests
- LAN, MAN, WAN, DNS, routers, protocols, packet switching, and client/server communication

## Run the number converter

From the repository root, run:

```bash
python3 mission-05-numbers-data/number_converter.py
```

Or change into `mission-05-numbers-data/` and run `python3 number_converter.py`. Enter a whole-number decimal value when prompted. The program displays the corresponding binary and hexadecimal forms.

## Learning summary

Following the missions demonstrates how familiar computer tasks connect to hardware, software, and data. A terminal makes file operations visible; an operating system coordinates programs and resources; Python makes number conversion easy to verify; and Git records changes so they can be reviewed and shared. The networking mission ties a browser request to DNS, protocols, routers, and servers.
