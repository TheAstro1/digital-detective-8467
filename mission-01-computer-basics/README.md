# Mission 1 — Know your computer

## 1. Task / objective
Trace one everyday computer activity through input, processing, output, and storage (IPOS). Identify hardware, software, and computer-based systems.

## 2. Work completed
### Example IPOS trace: type and save a document
| Stage | What happens | Example hardware / component |
|---|---|---|
| Input | Key presses enter text into the document. | Keyboard |
| Processing | The editor updates the document in memory and prepares the screen display. | CPU and RAM |
| Output | The current text and formatting appear on screen. | Display |
| Storage | Saving writes the document to a persistent drive; a sync service may upload a copy if enabled. | SSD; optional network storage |

The user supplies text with the keyboard. The application and operating system process the keystrokes, update the view, and save the document when requested.

## 4. My understanding
IPOS is a useful way to follow information through a computer: input is captured, the processor and software work on it, output communicates a result, and storage keeps data for later. The same pattern appears in many devices, not just laptops. Hardware is the physical equipment; software is the set of instructions that makes the equipment useful.
